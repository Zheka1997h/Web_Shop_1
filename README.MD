# WebShop — Простое веб-приложение на Python

## 📋 Описание
Учебный проект интернет-магазина, созданный без использования фреймворков 
на стандартной библиотеке Python. Демонстрирует понимание работы HTTP «под капотом».

##  Цель работы
- Научиться создавать HTTP-сервер без фреймворков
- Понять принципы обработки GET и POST запросов
- Сверстать страницы по макету с использованием Bootstrap 5

## 🛠 Технологии
- Python 3.14 (стандартная библиотека: `http.server`, `urllib.parse`)
- Bootstrap 5.3 (CDN)
- HTML5, CSS3
